**1. Welke aanpak kies ik?**

Ik kies regels voor klant- en factuurnummers, omdat ze snel en nauwkeurig zijn. Voor categorieën gebruik ik een LLM, omdat die de betekenis van een ticket beter begrijpt.

**2. Wat is het voordeel van JSON Schema?**

JSON Schema zorgt ervoor dat het antwoord de juiste structuur heeft, maar garandeert niet dat de inhoud correct is.

**3. Wat heb ik geleerd over privacy?**

Bij een lokaal taalmodel blijven de gegevens op mijn laptop. Bij een externe API worden ze doorgestuurd. Daarom moet ik rekening houden met de GDPR.
