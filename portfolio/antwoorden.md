# Mijn AI-app

Eén of twee zinnen: wat doet de app, en voor wie?

## Hoe start je ze?

```bash
cd portfolio
uv run fastapi dev api.py
```

## De vragen

Antwoord kort, met je eigen cijfers waar het kan.

1. Welke modellen gebruik je, en waarom deze?
2. Wat zegt de model card van elk model (waarvoor, talen, trainingsdata, licentie, benchmark), en klopt dat met je eigen meting?
3. Waarom via een API of op je laptop, per model?
4. Wat is de eenvoudigste aanpak, en wat doet jouw aanpak beter?
5. Hoe heb je gemeten of het werkt? Op welke voorbeelden, met welk resultaat?
6. Welke data verlaat je laptop, en naar wie?
7. Wat gebeurt er als een model fout antwoordt, of als een dienst niet antwoordt?
8. Hoe snel is het, en wat zou het kosten met veel gebruikers?
9. Weet de gebruiker dat er AI in zit? Wie beslist uiteindelijk?
