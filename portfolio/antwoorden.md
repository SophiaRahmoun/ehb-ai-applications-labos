# Mijn AI-app

Eén of twee zinnen: wat doet de app, en voor wie?

## Hoe start je ze?

```bash
cd portfolio
uv run fastapi dev api.py
```

## Vragen over je app

Voorbeelden van vragen die je bij de verdediging kan krijgen. Je hoeft dit niet in te dienen; schrijf gerust je antwoorden op om je voor te bereiden, met je eigen cijfers waar het kan.

1. Welke modellen gebruik je, en waarom deze? Denk aan de kwaliteit op je eigen voorbeelden, de snelheid, de kosten, en of het model via een API of op je laptop draait.
2. Wat zegt de model card van elk model (waarvoor, talen, trainingsdata, licentie, benchmark), en klopt dat met je eigen meting?
3. Wat is de eenvoudigste aanpak, en wat doet jouw aanpak beter?
4. Hoe heb je gemeten of het werkt? Op welke voorbeelden, met welk resultaat?
5. Welke data verlaat je laptop, en naar wie?
6. Wat gebeurt er als een model fout antwoordt, of als een dienst niet antwoordt?
7. Hoe snel is het, en wat zou het kosten met veel gebruikers?
8. Weet de gebruiker dat er AI in zit? Wie beslist uiteindelijk?
